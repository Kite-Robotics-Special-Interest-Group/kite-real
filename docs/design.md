# 设计：用输入扰动预测真机失败

## 1. 问题

VLA 在真机上的失败，大部分不是"策略完全不会"，而是"在某些视觉条件下退化"：光照变了、镜头脏了、目标被挡住、相机被碰歪。逐条做真机实验太贵，所以想问：

> **离线测得的"扰动 → 动作漂移"，能不能预测真机上"扰动 → 成功率"？**

## 2. 假设

**H1**：动作漂移（Δpos / Δrot / 夹爪翻转率）与真机成功率下降之间存在单调关系，Spearman ρ ≥ 0.5。

**H2**（更强）：在某一类扰动上标定出的映射，可以迁移到另一类扰动（例如用模糊标定，预测遮挡）。

**H0**（要能推翻自己的条件）：ρ < 0.3，或迁移后预测误差 > 20 个百分点 → 假设不成立，退回到"必须真机逐条测"。

## 3. 指标

| 指标 | 定义 | 采集成本 |
| --- | --- | --- |
| Δpos | 同一观测下，扰动前后动作块位置差的均值（mm） | 离线，秒级 |
| Δrot | 6D 旋转的测地角差（度） | 离线 |
| grip_flip | 夹爪开合判定翻转率 | 离线 |
| success@perturb | 真机在扰动下的任务成功率（每条 n=20） | 真机，分钟级 |
| 预测误差 | 用离线指标回归的真机成功率 vs 实测 | — |

## 4. 实验设计

**阶段 A（离线）**
- 真机采集一批固定观测（不同任务阶段、不同物体位置），每帧做 12 类扰动 × 4 档
- 计算 Δpos / Δrot / grip_flip
- 产出：与仿真阶段同一格式的表（可直接对比）

**阶段 B（真机）**
- 选取 3 类扰动（模糊 / 遮挡 / 光照），每类 3 档，每档 20 条真机 episode
- 记录成功率与失败模式（没抓到 / 抓飞 / 放偏 / 中途放弃）

**阶段 C（验证）**
- 用阶段 A 的漂移拟合阶段 B 的成功率（线性或单调回归）
- 留出一类扰动做交叉验证（检验 H2）
- 报告 ρ、拟合误差、失败模式分布

## 5. 数据格式（与 kite-bench 一致）

```
episodes/0000/
  meta.json      # instruction, seed, success, 相机/夹爪配置
  action.npy     # [T, 10] = ee_xyz(3) + rot6d(6) + grip(1)
  proprio.npy    # [T, 7]  = 关节(6) + 夹爪
  obs/0000_front.png ...
```

沿用同一格式的理由：训练脚本（`kite-bench/train.py`）不用改，仿真与真机数据可以直接混训。

## 6. 与已有工作的关系

- 输入扰动评测（ImageNet-C 一类）已很成熟，但**用在 VLA 动作输出上并回归到真机成功率**的工作还少
- 我们已有的优势：46 组仿真空扰基线、可复现的扰动实现、明确的失效模式（模糊最致命、遮挡改夹爪决策）

## 7. 风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 真机样本少（每档 20 条） | 置信区间宽 | 先做 3×3 档位，显著性不足再扩 |
| 扰动实现与真机退化不对应 | 离线指标无意义 | 先用"真实退化"（调焦、贴膜、挡板）校准扰动参数 |
| 任务太简单（单物体） | 成功率饱和在 100% | 选 3 个难度梯度任务 |
| 漂移与成功率非线性 | H1 需要用单调回归而非线性 | 用 Spearman + 分段回归 |
