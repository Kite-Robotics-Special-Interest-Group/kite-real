# 机械臂建模需要的数据

给 **su-tree** 的工作清单：目标是产出一份**与真机一致**的运动学模型，后续所有动作映射、相机标定、数据采集都依赖它。

## 一、几何数据（必做）

| 项 | 怎么测 | 精度要求 | 交付格式 |
| --- | --- | --- | --- |
| 各连杆长度 | 卡尺/卷尺，测关节轴线之间的距离（不是外壳尺寸） | ≤ 1 mm | 表格 + 手绘示意图 |
| 关节轴线方向 | 每个关节单独转动 ±30°，拍两张照片看运动平面 | — | 照片 + 说明 |
| 关节零位 | 手动摆到机械零位，记录编码器读数 | ≤ 0.1° | 表格 |
| 关节限位 | 慢速顶到限位（注意安全），记录编码器值 | ≤ 0.5° | 表格 |
| 夹爪行程 | 全开/全闭时两指间距 | ≤ 0.5 mm | 数值 |
| 指尖几何 | 指尖厚度、宽度、pad 材质 | — | 照片 + 尺寸 |
| 基座安装高度 | 台面到基座法兰的距离 | ≤ 1 mm | 数值 |

> 测量方法：优先找厂家 CAD/规格书，**再用实物核对**。两者冲突以实物为准，并在表里注明差异。

## 二、运动学标定（必做）

**采样表**：至少 15 组「关节角 → 末端实测位姿」

| 怎么采 | 要求 |
| --- | --- |
| 在可达空间内均匀取 15–20 个位姿（避免同一个平面） | 覆盖工作空间三个方向各 3 档 |
| 末端装一个尖针/探针，扎到已知坐标的标定点（标定板角点或台面上画好的网格） | 每个点测 3 次取平均 |
| 记录：6 个关节角（编码器原始值）+ 末端在世界坐标的 (x, y, z) | 位置精度目标 ≤ 1 mm |

**用途**：验证 URDF 的连杆长度与关节零点；用最小二乘拟合修正 DH 参数。

**验收**：用校正后的 URDF 做正运动学，与 15 组实测位姿的**平均误差 ≤ 5 mm**（理想 ≤ 2 mm）。

## 三、动力学数据（可选，做抓取力控制时才需要）

| 项 | 来源 |
| --- | --- |
| 各连杆质量 | 厂家参数，或拆下称重 |
| 质心位置 | 厂家参数，或 CAD |
| 惯量张量 | 厂家参数，或按几何近似 |
| 关节摩擦 | 空载匀速转动，记录电流/力矩 |

## 四、与相机相关的配套数据

虽然由同学 A 负责，但**建模时需要一起对齐**：

| 项 | 用途 |
| --- | --- |
| 相机-基座外参 | 把相机看到的物体位置转换到机械臂基座坐标 |
| 腕部相机手眼变换 | 腕部视角下的动作映射 |
| 相机内参 | 像素 → 三维反投影 |

**约定**：所有坐标系以**机械臂基座为原点**（x 前、y 左、z 上），相机、物体、标定点全部转到这个系下。

## 五、交付物清单

```
arm/
  urdf/wx250s_calibrated.urdf     # 校正后的 URDF（含实测连杆与限位）
  urdf/meshes/                    # 网格（可沿用厂家 STL）
  calib/geometry.csv              # 连杆/限位/夹爪测量表
  calib/kinematics.csv            # 15+ 组「关节角 → 末端位姿」采样
  calib/report.md                 # 拟合结果与残差，说明哪些参数改过
  photos/                         # 零位、限位、测量示意图
```

## 六、验收标准

1. 正运动学与 15 组实测位姿：**平均误差 ≤ 5 mm**
2. 同一目标位姿重复 10 次，末端重复定位：**≤ 2 mm**
3. 关节限位与实测一致（不能出现"软件允许但机械到不了"）
4. `report.md` 里写清：改了哪些参数、为什么改、改前改后的残差

## 七、注意事项

- **测轴线距离，不是外壳**：很多连杆外壳有斜角，量外壳会偏 5–10 mm
- **零位要一致**：所有数据用同一套零位定义，写进 `report.md`
- **别在通电状态下用手掰**：测限位时用低速点动
- 卡尺精度不够时，用"标定板 + 相机"反推（同学 A 的工具可以直接用）
